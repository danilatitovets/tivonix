# Данные, которые владелец TIVONIX должен предоставить

Следующие поля **не заполнены** в конфигурации и не выводятся на сайте намеренно.
Добавьте их в `.env` (или передайте команде для `src/config/siteConfig.ts`).

## Юридическое лицо

| Переменная | Описание |
|------------|----------|
| `VITE_LEGAL_COMPANY_NAME` | Полное юридическое наименование |
| `VITE_LEGAL_UNP` | УНП / регистрационный номер |
| `VITE_LEGAL_ADDRESS` | Юридический адрес |
| `VITE_LEGAL_PHONE` | Контактный телефон для публичного отображения |

## Контакты

| Переменная | Описание |
|------------|----------|
| `VITE_HELLO_EMAIL` | Публичный `hello@tivonix.tech` — показывается **только** после явной настройки |
| `VITE_LINKEDIN_URL` | Ссылка на профиль компании или основателя (LinkedIn) для footer и schema.org `sameAs` |

## Аналитика и Search Console

| Переменная | Описание |
|------------|----------|
| `VITE_GA_MEASUREMENT_ID` | ID потока GA4 (формат `G-XXXXXXXX`) |
| `VITE_HOTJAR_ID` | ID сайта Hotjar |
| `VITE_GOOGLE_SITE_VERIFICATION` | Meta-тег верификации Google Search Console |
| `VITE_GOOGLE_ADS_ID` | (опционально) Google Ads для конверсий |
| `VITE_GOOGLE_ADS_CONVERSION_LABEL` | (опционально) метка конверсии |

## Отзывы клиентов

Для публичного блока отзывов желательны **проверяемые** данные:

- полное имя (или явное согласие на «Client name withheld»);
- должность и компания;
- ссылка на LinkedIn, сайт компании или опубликованный отзыв;
- подтверждение клиента на публикацию цитаты.

## Кейсы

- Разрешение клиентов на публикацию **бюджета и сроков** в маркетинговом тексте;
- Подтверждение, что внешние проекты доступны для статуса «Live» / внешней ссылки.

## Партнёрская панель

- Подтверждённый production URL (`VITE_PARTNER_PANEL_URL`) — сейчас: Railway panel из `.env.example`.
