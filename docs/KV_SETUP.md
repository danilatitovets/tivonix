# Счётчик визитов в боте (/admin)

Счётчик работает **без БД**: число хранится в памяти сервера.

- При заходе на сайт вызывается `/api/visit` — счётчик за день увеличивается.
- По команде `/admin` в боте показывается **Визитов сегодня: N**.

**Ограничение:** на Vercel запросы могут обрабатываться разными инстансами. Поэтому число приблизительное: при холодном старте инстанса счётчик обнуляется, а бот при запросе может попасть на другой инстанс и увидеть 0. При небольшой нагрузке часто один инстанс обрабатывает и визиты, и бота — тогда цифра стабильнее.

Если нужна точная статистика без обнулений, можно подключить Redis в Vercel (Storage → Create Database → Redis) и вернуть сохранение в KV — тогда счётчик будет общий для всех инстансов.
